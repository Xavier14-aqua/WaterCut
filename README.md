## 下载与开始

完整解压 `WaterCut-win32-x64-1.4.4.zip` 后运行 `WaterCut.exe`。用户无需安装 Node.js 或系统 FFmpeg；不配置 AI Key 也能手工创作。首页可点击“用官方示例体验一条故事”，示例含程序生成的图片、情绪卡、场景记录和五个镜头，不包含开发者私人素材。

1. 在“总库 → 全局总库”记录文字、情绪卡或场景；导入图片、视频、音频。情绪卡可用色环、饱和度、明度或颜色值编辑主色条，灵感按相近色系筛选。已确认的关联显示卡片标题，点击可查看。
2. 勾选卡片“孵化为项目”，或新建项目后从资源栏引用全局内容。
3. 在白板整理、连线，确认卡片顺序后生成镜头骨架；也可直接写脚本。
4. 脚本可切文档 / 双栏视图；“+ 标题”创建独立分组和首条草稿，组内可继续添加。段落和标题分组可用上移 / 下移按钮或拖动手柄排序；正文转镜头后与分镜共用动作 / 对白。
5. 给镜头拖入候选素材，或从主画面下拉框直接选择项目图片 / 视频；在详情中手动添加或移除灵感来源。设置视频入出点后切换粗剪预览，在时间轴换序或拖边调整时长。
6. 用待拍清单检查缺口，按场景 / 昼夜分组，导出 CSV。
7. 点击顶部“版本与交付”，创建命名快照、恢复历史、导出项目包或 A4 分镜 / 待拍清单 PDF。

“总库 → 项目库”可下拉选择任意已登记的本地项目，单独查看它的灵感与素材；离线项目不能打开。这里的灵感编辑点击“保存”后只写入所选项目。浏览其他项目不会切换当前工作室，点击“进入工作室”才进入所选项目。

两类库的“灵感”都支持收纳盒：选“收纳盒与未收纳”后新建盒子，把卡片拖进去，或勾选多张后“收纳所选”；点开盒子查看内容，也可重命名、移出或删除盒子。删除盒子会把卡片放回未收纳。“全部平铺”始终展示所有卡片，搜索、类型和颜色筛选继续生效；盒子计数按当前筛选条件计算。每张卡归一个盒子，各库独立保存，显示方式会记住。

## 版本与交付

- **快照**：保存当前项目的内容、白板、脚本、镜头、候选和裁剪；恢复前自动创建当前状态快照。快照保留素材指纹和依赖，不把所有旧快照嵌套保存。删除快照只移除记录，历史原件不自动回收。
- **项目包**：默认带原件和全部快照，只汇集该项目所需的全局素材、局部素材、候选与灵感附件；按内容去重，导出副本中的引用改为本地路径，原项目保持不变。缺失或不带原件时，结果明确标记“不完整”。
- **导入**：首页“导入项目包”，校验路径、大小、SHA-256 和数据库后创建独立项目副本；无需原来的全局库，不覆盖已存在项目。加入总库仍是另一项明确操作。
- **PDF**：支持 A4 横版 / 竖版，带缩略图、对白、拍摄信息、状态、来源和页码；长文本自动续行，图片缺失显示占位。待拍清单与 CSV 共用导出数据。
- **剪映交接**：在剪映设置中查看“草稿位置”，WaterCut 导出时直接选择这个本地草稿根目录，再刷新或重启剪映打开新项目。实测为 11.8.0.14778 的单视频轨直切、PNG、H.264/AAC 与 WAV BGM。素材使用绝对路径，换电脑推荐导入 WaterCut 项目包后重新交接；剪映默认淡变曲线与 WaterCut 线性预览有差异。
- **媒体参数**：随包提供固定版本的 MediaInfo WebAssembly，独立 worker 离线读取容器、时长、宽高、编解码与音视频流；超时可取消，未知字段留空。能探测不代表当前系统能解码所有格式；VFR 不按平均帧率推算每帧。

## 本地数据与共享规则

项目和全局库保存在源码与程序之外；存储设置会跨重启保留，可在左下“存储”更改。

- 从仓库开发或运行仓库 `out/` 程序，默认项目位于仓库旁 `WaterCut Projects/`，总库位于同级 `WaterCut Library/`。
- 仓库外运行便携 ZIP，首次默认使用用户文档中的 `WaterCut Projects/` 与 `WaterCut Library/`。
- 修改项目目录只影响以后的新项目。打开 / 新建另一总库不会自动搬迁旧库；库的原有项目仍保留来源标识。
- 全局库使用 `library.sqlite` 和 `objects/` 保存受管原件，导入时复制并按 SHA-256 去重。项目保存素材引用，各镜头裁剪、备注和布局互不影响。
- 引入项目的灵感保存当时的内容快照。项目编辑不回写总库；来源更新后可以比较并明确选择应用更新。
- 总库“隐藏”不删除原件、不破坏项目引用；移除项目素材引用不会删除全局原件。项目独有素材仍放在自己的 `assets/`。
- “将项目内容加入全局库”可在取消后继续，原项目副本保留。全局原件重新定位必须匹配原内容哈希，避免其他项目意外换片。

**跨电脑迁移**：在“版本与交付”保留“包含原件”，导出完整项目包 ZIP；新电脑解压程序 ZIP 后，在首页导入项目包即可。只复制仍引用总库的原始 `.watercut` 文件夹依然不完整。快照保存编辑状态，项目包承担含原件的迁移与备份。

当前项目数据库格式为 v11，全局库格式为 v4，快照文档 / 项目包格式为 v1；格式号与应用版本独立。打开旧项目和旧库会先一致备份再升级，旧版应用不能写入较新的格式。收纳盒和卡片归属随项目快照、项目包保留；旧快照默认无收纳盒，旧 v9 项目包仍可导入。

镜头、项目灵感和脚本编辑延迟自动保存；保存失败保留编辑并可重试。全局灵感表单点击“保存”；关闭应用会等待项目保存。视频按入出点保留原声播放，图片和无素材镜头按相应时长展示；缺失 / 无法播放的媒体退回文字占位。参考音频可单独试听；连续 BGM 在粗剪底部配置，原声与音乐有独立音量。粗剪基于浏览器媒体事件，不保证逐帧精度。

v1.2.1 修复卡片详情与白板选中状态的循环更新。详情异常会显示可关闭的恢复面板；若页面崩溃或退出时 5 秒未回复，由主进程提供“继续等待 / 退出程序”的原生确认。错误信息仅写入本机用户配置目录的 `renderer-errors.log`，不会进入项目或分发包。

## AI 草案与隐私

AI 使用用户自己的 OpenAI API Key 和模型 ID，需要网络，可能产生服务费用。密钥通过 Electron safeStorage 加密保存在本机用户数据目录，不进入项目或 ZIP。

只有主动生成时，所选灵感的文字、标签、备注，以及目标镜头的画面、对白、时长、景别、运镜才会发送；不发送文件、实际对象 ID、路径或地点专用字段。支持故事路线选择、逐条配画面建议、体检标注及明确插入补镜，采纳时再次核对原稿。灵感回声仅在本机检索。待确认建议只留在本项目数据库，不进入正式快照 / 项目包。没有密钥或生成失败时，手工创作照常使用。详见 [隐私说明](./PRIVACY.md)。

## 开发与验证

开发需要 Windows、Node.js 24 和 npm：

```powershell
npm ci
npm run check
npm test
npm start
```

```powershell
npm run make
npm run smoke -- --scenario=core --packaged
npm run smoke -- --scenario=inspiration --packaged
npm run smoke -- --scenario=delivery --packaged
npm run smoke -- --scenario=editor --packaged
npm run smoke -- --scenario=organization --packaged
npm run smoke -- --scenario=professional --packaged
npm run audit:dist
```

`package` 生成 `out/WaterCut-win32-x64/`；`make` 生成 `out/make/zip/win32/x64/WaterCut-win32-x64-1.4.4.zip`。六组 smoke 在隐藏窗口中加载实际 `app.asar`，使用临时用户配置和自制素材；报告位于 `out/review-core/`、`out/review-inspiration/`、`out/review-delivery/`、`out/review-editor/`、`out/review-organization/`、`out/review-professional/`。额外 BGM 场景和旧参数别名见 [开发与验证](./docs/development/README.md)。`audit:dist` 校验 ZIP 与已测试程序一致、许可和 WASM 完整、无私人数据，并生成 SHA256SUMS.txt。构建附带源码树 / 锁文件摘要与 Git 提交信息；尚无提交时如实记录为空。

源码、测试、配置、许可证和文档进入 Git；`node_modules/`、`.vite/`、`out/`、私人项目与全局库不进入仓库。应用采用 MIT 许可证，ZIP 附带运行依赖及 Electron/Chromium 的许可文本。当前为未签名预览版，Windows 可能显示来源提示。

阶段 4A 使用 v1.4.0 起步，v1.4.1 完成剪映基础交接实机验收，后续补丁继续递增。历史阶段 4A 包位于 `out/stage4a`；本机 v1.4.4 最终包位于 `out/architecture-v1.4.4`，具体校验值见 [发布清单](./docs/releases/RELEASE_CHECKLIST.md)。使用前先退出旧版，再解压新 ZIP。原生验收素材保留在仓库外，不进入程序或 Git。
