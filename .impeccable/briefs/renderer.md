# 桌面创作界面

Mode: Operate。范围：项目首页、总库、工作室五流程及其详情与对话框。

## Direction contract

THESIS：按用户六张参考图实现可日常操作的米白创作工作台，保留原有功能、数据与保存规则。

OWN-WORLD：纸色底、墨黑细框、钴蓝主操作、珊瑚色连接点；淡线轨道与准星作为统一几何语言。字体本地加载，图形由原生 SVG 精确绘制。

STORY：先在项目大厅打开或创建项目，再从左资源栏进入白板、脚本、分镜、粗剪和清单；始终能找到当前项目、详情和保存状态。

FIRST VIEWPORT：首页有左轨、顶栏、标题与创建操作、几何封面项目卡。工作室为 76 / 260 / 弹性 / 300 px 四列，72 px 顶栏与 32 px 状态栏；1440、1280、1000 宽度均需实测。

FORM：seed: none (pinned)，用户原话“把前端按这个渲染”，附六张完整界面。采用这些屏幕的构图，不追加新的风格选择环节。保留 Windows 原生窗口装饰。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 验收范围

使用隔离的合成数据，查看六个参考页面、总库、非空检查器与对话框；检查窄窗口、长文本、溢出、焦点与对比。运行现有原生保存、拖拽、媒体、BGM 和交付回归。源码和个人素材不作为测试输入。

## Finish review

2026-11-24 独立复核的最终 disposition 为 ship。首轮要求补齐镜头键盘入口、模态焦点行为和已检索完毕的总库截图；三项均在修正复核中判为 resolved。复核依据三种宽度的原生截图、74 项界面检查及 15 次可信按键记录。没有运行自动设计检测或像素差分；新交付图形均为原生几何代码，没有新增需要生成来源说明的运行时栅格素材。
