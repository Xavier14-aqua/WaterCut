# WaterCut v1.3.0 预览版

阶段 3：可靠保存与交付，Windows x64 免安装 ZIP。

- 工作室新增“版本与交付”：命名快照、恢复前自动快照、事务恢复与历史素材依赖保留。
- 导出独立项目包，按需带全部原件与快照；包含全局引用、候选和灵感附件。导入到独立身份，不依赖旧总库，也不覆盖已有项目。
- 新增 A4 横版 / 竖版分镜 PDF 与待拍清单 PDF，带主画面、拍摄信息、来源、续行和页码。
- 新增固定版本 MediaInfo 离线探测；宽高、时长、编解码与流信息持久化，未知字段明确保留为空。无需安装系统 FFmpeg。
- 项目格式 v9、总库 v2，升级前一致备份；保留 v1.2.1 的卡片白屏与退出修复。
- ZIP / asar 验收与 SHA256SUMS.txt，构建随包记录源码树、锁文件、Git 提交与 WASM 摘要。未有 Git 提交时记录为空，不冒充正式发布提交。

完整解压 `WaterCut-win32-x64-1.3.0.zip`，运行 `WaterCut.exe`。在“版本与交付”导出完整项目包，在另一份程序首页导入即可；不带原件或缺失原件的包明确标记为不完整。

本机隔离环境已验证独立导入与预览；另一 Windows 电脑仍需发布前实机检查。当前未签名，仍为预览版。分支版本、BGM、专业剪辑时间线和正式视频输出继续按后续阶段推进。
