## 2026-11-17：候选画面选择故障修复

- **用户反馈**：从素材库选择“添加候选画面”后提示“操作失败：镜头或画面内容不存在”。
- **原因**：界面的下拉框以空值受控；`run()` 会先等待待保存内容落盘，期间 React 重绘把下拉框恢复为空。原处理函数在异步等待后才读取事件对象中的选择值，导致传给主进程的素材 ID 为空。数据库侧添加候选画面的测试原本通过。
- **使用与改动**：在 React `onChange` 同步读取 `e.currentTarget.value` 并保存在局部变量，随后将固定的素材 ID 传入 Electron IPC；同时修正同样写法的“主画面”和“参考音频”下拉框。未更改数据库格式和项目文件。
- **效果**：异步保存和界面重绘不会改变已经选定的素材 ID，避免空 ID 触发“镜头或画面内容不存在”。
- **验证**：`npm test` 14 项通过；`npm run typecheck` 通过；`WATERCUT_BUILD_OUT=out-candidate-fix` 下 `npm run package` 通过，生成 `out-candidate-fix/WaterCut-win32-x64/WaterCut.exe`。实际界面操作待用户复验。
