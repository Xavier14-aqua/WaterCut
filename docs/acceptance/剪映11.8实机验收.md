# 剪映专业版 11.8 实机验收

2026-11-19，Windows x64，剪映专业版 **11.8.0.14778**（界面显示 11.8.0）。结论：**本记录限定的基础交接流程通过**。v1.4.0 交付时未安装剪映的待验收项，在 v1.4.1 中补齐；不代表所有剪映版本、编码和复杂剪辑效果都兼容。

## 验收路径

先打开 v1.4.0 合成样例，确认模板能被真实剪映接收。随后由最终 v1.4.1 包的 `app.asar` 通过正常导出接口，直接向剪映设置中的本地草稿根目录生成新草稿。没有手改该草稿的 JSON、修补路径或登记剪映草稿目录索引。

剪映从本地草稿列表发现项目，打开后原生导出 MP4。再用 FFprobe / FFmpeg 解码该成片，与 WaterCut 导出的原件、PNG 和时间线分别比对。FFmpeg 仅用于开发验收，用户运行便携版不需要安装。

所有内容均为程序合成测试图、时间码视频、文字占位与合成音频。未使用私人项目、密钥或素材，未发布作品或上传云空间，也未解密剪映保存后的工程。剪映 Agent CLI 要求运行令牌，因此本轮采用桌面界面完成实机操作。

## 已知边界

- 导出时应直接选择剪映设置中的“草稿位置”。新草稿包含绝对素材路径，生成后移动整个目录不能保证路径有效。跨电脑推荐导入 WaterCut 项目包后重新导出，或在剪映内重新定位素材。
- 剪映的默认淡变曲线与 WaterCut 实时预览的线性曲线有差异；本次保留的是淡变时长和目标音量，不保证包络逐采样相同。
- 实测编码仅为 H.264/AAC MP4、PNG 和 WAV，序列为 30 fps、单视频轨直切及一条 BGM。界面开放的其他容器、整数帧率和有限音轨范围仍需各自样例验证。
- 未涵盖特效、转场、字幕轨、变速、多视频轨、VFR 和分数序列帧率。此适配不是剪映官方稳定导入协议；不要用 WaterCut 改写剪映保存升级后的草稿。

## 正常操作步骤

1. 在剪映设置中查看本地“草稿位置”。
2. WaterCut → 项目工作室 → 版本与交付 → 导出剪映草稿文件夹，选择上面的根目录。
3. 刷新或重新启动剪映，在“本地草稿”打开新项目。
4. 在剪映继续精剪并导出成片。WaterCut 附带的 CSV / timeline.json 保留完整分镜文字。
