# WaterCut v1.3.1

2026-11-19。根据实际使用反馈修复总库、脚本与分镜交互，继续提供 Windows x64 免安装 ZIP。后续补丁依次使用 v1.3.2、v1.3.3。

## 改动与入口

| 反馈 | 当前行为 |
| --- | --- |
| 情绪卡主色条需要色环 | 情绪卡详情新增色环、饱和度 / 明度、颜色值与系统选色器；可添加、替换、移除最多 6 种主色，支持键盘与鼠标 |
| 已手动关联只显示编号 | 显示对方卡片完整标题和关系备注，点击标题查看；即使对方不在当前检索页也能读取 |
| 总库需要区分全局与项目 | “总库”新增“全局总库 / 项目库”；项目库下拉选择已登记项目，分别看灵感 / 素材。浏览不切换工作室，需点击“进入工作室” |
| 灵感按相似颜色筛选 | 全局总库与项目库都可选择红、橙、黄、绿、青、蓝、紫、粉、棕、黑白灰色系；任一主色匹配即入选，全局筛选在分页前计算 |
| 脚本需要标题分块和多稿 | “+ 标题”创建标题与首条草稿，每组可加多条；旧正文保持原状，可用“添加标题”纳入分组 |
| 脚本需要调整位置 | 段落支持上下按钮和跨组拖动；标题分组支持整组上下移动 / 拖动。关联镜头按脚本顺序同步，不复制一套分镜数据 |
| 分镜不能手动挑灵感来源 | 镜头详情“添加项目灵感”可手动增删来源；自动去重，移除来源不会删除灵感卡。卡片删除后保留已有摘录 |
| 主画面下拉不能选择 / 更换 | 在等待保存之前捕获所选素材 ID；可从候选或其他项目图片 / 视频切换，也可清空主画面，候选保留；粗剪同步使用新画面 |

项目库浏览中的灵感编辑点击“保存”后只写入所选项目；若正是当前工作室项目，工作室同步更新。工作室原有项目卡片、正文、镜头仍延迟自动保存。主画面、来源和排序操作会先完成待保存编辑，再执行事务写入。

## 兼容与分发

应用版本更新为 1.3.1；项目数据库仍为 v9、全局库为 v2，快照 / 项目包格式仍为 v1，没有新增数据库迁移。标题复用现有脚本 heading 记录，排序及来源通过受控 IPC 写入项目；已有素材与来源关系保留。

完整解压 `WaterCut-win32-x64-1.3.1.zip` 后运行 `WaterCut.exe`。程序与用户项目 / 总库继续分离，本次验证只使用临时合成数据。
