# WaterCut 界面主题与样式

## 从哪里开始

`renderer/main.tsx` 引入 `styles/index.css`。该文件只声明加载顺序；`tokens.css` 定义纸色、正文、主色、状态色、字体和边线。调整主题时优先修改变量，避免到多个组件里寻找颜色值。

| 文件                              | 对应内容                               |
| --------------------------------- | -------------------------------------- |
| `base.css`                        | 基础控件、文字、焦点、图形、选择与滚动 |
| `shell.css`                       | 左轨、顶栏、流程导航、保存与底栏       |
| `home.css`                        | 首页介绍、项目大厅和几何封面           |
| `collections.css` / `library.css` | 收纳、色环、总库、素材与精华           |
| `workspace.css`                   | 资源栏、主区与检查器                   |
| `board.css` / `script.css`        | 白板、连线、脚本分组与双栏             |
| `storyboard.css`                  | 分镜故事板、清单、筛选与来源           |
| `preview.css`                     | 播放器、时间线、裁剪柄、BGM 和混音     |
| `ai.css` / `panels.css`           | AI 建议与回声、交付 / 存储 / 恢复面板  |
| `responsive.css`                  | 窄窗口、减少动态效果与打印             |

## 组件与行为边界

`ui/Icon.tsx` 定义一致的线性图标。`ui/BlueprintArt.tsx` 只绘制几何轨道、准星和取景框，均不接收鼠标操作。项目封面不读取个人素材，也不引入远程图片或字体。

`ui/Modal.tsx` 集中处理对话框名称、Tab 闭环、背景 `inert`、Esc 和焦点恢复。业务组件继续传入自己的关闭动作与忙碌规则，不在多个表单里复制焦点逻辑。分镜编号的详情按钮保留原有卡片点击行为，同时提供明确的键盘入口。

`app/views` 继续负责页面组装；`features` 保留编辑与播放行为。改外观不改 `app/save` 的队列、`preview/engine` 的共同音频时钟或后台事务。用户的图片、视频、情绪色彩与色环属于内容，不跟随主题重映射。

## 修改后如何检查

先运行 `npm run check`，再构建并运行 `npm run smoke -- --scenario=interface --packaged`。新页面需要检查三个桌面宽度、长文本、非空详情与对话框；布局可以纵向滚动，但导航和编辑操作不能溢出所属列。

报告与截图在 `out/review-interface/`。该检查只覆盖实际捕获的页面和代表性文字，不代替所有交互、人工听音或剪映实机验收；功能回归仍使用其他原生场景。
