## 对应表

- `file-moves.json`：旧文件到新入口，包含纯搬迁时的摘要和导入路径修改数量。
- `function-moves.json`：类型、常量和函数拆分后的实现位置；`baselineFile` 对应重构前文件。
- `script-moves.json` 与 `document-moves.json`：开发脚本和历史资料的位置。
- `ipc-channels.json`、`worker-commands.json`：通信分组及固定数据线程命令。
- `app-view-bindings.json`：工作台状态与视图组合的边界。
- `inspector-moves.json`：检查器的选中资源读取与三类表单拆分，记录提取前片段摘要及作用域参数替换。

## 回退方式

本次源码内的 SQL 不变量按跨平台统一换行后的实际值核对，模板与合成样例也有独立摘要。它们证明文本完整性；事务和保存顺序同时由保留的业务实现、集成测试和原生检查验证。
