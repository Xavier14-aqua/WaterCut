# WaterCut 迭代 2 验收清单

此文件保留早期白板 / AI 的验收步骤；当前 v1.2.0 的完整阶段 1、2 验收见 [阶段1-2实现与验收](./阶段1-2实现与验收.md)。

运行 `out/WaterCut-win32-x64/WaterCut.exe`，建议使用独立测试项目。首次打开旧项目会生成 `project.sqlite.before-v7.bak`。

## 灵感白板

- [ ] 新建项目时确认页面提示的默认位置为仓库同级的 `WaterCut Projects/`；导入素材后确认项目目录内 `assets/` 有副本，原始文件仍在原处。
- [ ] 从最近项目打开旧项目，确认路径已指向仓库同级的 `WaterCut Projects/`，分镜和素材仍可读取。
- [ ] 新增至少三张灵感卡片；在白板拖动它们，关闭并重新打开项目，位置保持一致。
- [ ] 左下角缩放、适配和交互按钮图标清晰、大小一致，可正常点击。
- [ ] 从任一卡片的上、右、下、左连接点，分别拖到另一张卡片任意一边的连接点；重开后各条连线仍连接原来的点。
- [ ] 白板下方“连线”列表显示每条连接；点击其中一条的“删除”，线条消失，重新打开后仍不存在。
- [ ] 点击白板上的线条，使用“删除选中连线”或 Delete 键删除；输入框获得焦点时按 Delete 不会误删连线。
- [ ] 删除一张带连线的灵感卡片，相关连线一并消失，其他灵感与素材保留。

## AI 草案

- [ ] 不配置 Key 时，仍可使用灵感箱、白板和手工分镜。
- [ ] 输入可用的 OpenAI 模型 ID 与 API Key，保存设置；重启后显示已保存密钥，但输入框不回显密钥。
- [ ] 勾选一张或多张灵感，生成 5～10 个镜头草案；已有分镜在生成阶段不变化。
- [ ] 修改草案的画面、动作/对白与时长，移除一个镜头；点击“确认加入分镜”，检查修改后的镜头按顺序加入，重开后仍在。
- [ ] 再生成一次草案并点击“放弃草案”，已有分镜不变化。
- [ ] 用无效模型或断网测试失败提示；已有分镜和项目内容保持不变。测试完可在界面清除本机密钥。

## 当前边界

AI 在线调用需要用户自己的 API Key 和可访问 OpenAI API 的网络；我们没有在开发环境使用真实密钥进行端到端调用。草案目前仅在界面暂存，关闭应用或切换项目会丢弃未确认草案。版本快照与项目包属迭代 3。
