# WaterCut v1.2.0 预览版

阶段 1、阶段 2 合并交付，Windows x64 免安装 ZIP。

新增全局灵感 / 素材库、情绪卡和场景记录、跨项目原件引用、时间与标签检索、卡片关联及项目孵化。项目内卡片与裁剪独立，支持把旧项目内容加入总库并保留原副本。

新增四区工作台和白板 / 脚本 / 分镜 / 粗剪 / 清单视图。文档与双栏脚本共用镜头正文，支持段落转镜头、拆分合并、来源追踪。分镜支持景别、运镜、状态和候选素材；粗剪增加进度定位、时间轴换序、拖边和待优化标记。待拍清单可分组并导出 CSV。

本机存储目录可选择并持久化。数据库升级前备份；新增后台数据 worker、受控媒体协议、SHA-256 去重与原件重连校验。示例项目只使用程序生成素材，AI 请求只发送已披露的文字字段。

完整解压 `WaterCut-win32-x64-1.2.0.zip`，运行 `WaterCut.exe`。无需 Node.js 或系统 FFmpeg，不配置 AI 也可创作。当前未签名，Windows 可能显示来源提示。

项目格式从 v7 升为 v8。引用总库的项目跨电脑使用时需同时复制对应全局库，并在新电脑的存储设置中选择；只复制项目文件夹不构成完整备份。独立项目包、版本快照、PDF、连续 BGM 和正式视频导出仍按后续阶段推进。
