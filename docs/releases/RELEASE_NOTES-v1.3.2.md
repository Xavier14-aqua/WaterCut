# WaterCut v1.3.2：灵感收纳盒

2026-11-19。全局总库和项目库都支持手动整理随手记、情绪卡和场景记录。

## 使用

1. 打开“总库”，选择“全局总库”，或在“项目库”下拉选项目，再进入“灵感”。
2. 选择“收纳盒与未收纳”，输入名称后新建盒子。三类卡片可以混放，一张卡片归一个盒子。
3. 把卡片拖到盒子上，或勾选多张、选择目标盒后点击“收纳所选”。
4. 点击盒子查看其中卡片；用“全部收纳盒”返回。可在盒内重命名，选择卡片移出，或移入另一盒。
5. 删除盒子会将其中卡片放回未收纳；也可拖到“未收纳”栏移出。卡片、原有标签和白板布局保留。

“全部平铺”显示所有灵感，无论它们是否已收纳。“收纳盒与未收纳”显示各盒入口，以及没有归入盒子的卡片。搜索、类型与颜色筛选继续生效；全局总库也可继续按时间或标签筛选。盒子数量按当前筛选统计，空盒仍可打开。全局总库和每个项目在本机各自记住显示方式。

## 保存与兼容

- 收纳名称与归属写入各库 SQLite，操作成功即保存。各项目与全局库相互隔离；引用全局卡片不会自动继承全局收纳关系。
- 项目收纳加入版本快照和独立项目包；恢复前仍自动保存当前状态。旧快照缺少的收纳字段按空盒 / 未收纳处理。
- 项目数据库 v9 → v10，全局库 v2 → v3。升级前使用一致备份，旧应用会拒绝较新的格式。项目备份名为 `project.sqlite.before-v10.bak`（重复备份附 UUID），全局备份名含 `.before-v3.`。
- 新程序继续导入 v9 项目包：只读校验源数据库，再重建为 v10；不会直接迁移或执行原包中的写触发器。快照文档 / 项目包格式保持 v1。
- 收纳盒名称最多 80 个字符，同一库不允许同名，每库最多 1000 盒；批量写入先验证全部卡片属于当前库，失败回滚。
