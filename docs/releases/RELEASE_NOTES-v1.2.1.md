# WaterCut v1.2.1：卡片白屏与退出修复

日期：2026-11-19。继续提供 Windows x64 免安装 ZIP；数据库格式保持项目 v8、总库 v1。

## 修复

- 白板原先通过 `onSelectionChange → 父组件选中列表 → 白板节点` 双向回写状态。选中卡片、切换总库再返回工作室时可能循环更新，触发 React 错误 #185，使整个页面卸载。现在仅处理节点变更事件中的实际选择动作，稳定事件回调；侧栏勾选仍可同步白板，返回工作室保留选中项。
- 卡片检查器与整个应用分别增加错误边界。详情渲染失败时，工作台和待保存项目状态保留，可关闭详情并重新打开；整个页面失败时提供重载 / 退出入口。
- 卡片时间字段增加有效性检查，避免无效日期在 `toISOString()` 中抛出异常。
- 关闭流程使用请求编号核对保存回执。正常退出等待最后一次编辑落盘；页面崩溃、无响应或 5 秒不回复时，由主进程提供原生“继续等待 / 退出程序”确认，默认继续等待。旧请求回执不会关闭新一轮请求。
- 错误堆栈写入本机用户配置目录 `renderer-errors.log`，大小受限；不会上传、写入项目或进入 ZIP。
- 流程回归发现粗剪首帧的动画时间戳可能早于 effect 初始化时间，导致进度变负并立即暂停；现将时间增量限制在非负范围。

## 验证

- 类型检查及 51 项自动测试通过。
- 18 项 Electron 卡片 / 退出回归覆盖：左侧三张卡连续打开、白板点击、总库切换、选中项恢复、侧栏勾选同步、注入详情渲染异常后的恢复、最后一次编辑立即关闭仍保存，以及实际终止渲染进程后的原生确认退出。
- 用原项目的临时副本在正常可见窗口和 GPU 渲染下验证；所有编辑写入临时副本，原项目保持不变。
- 重新构建 ZIP 后执行上述包内回归及原有 19 项流程检查；分发目录重新生成 SHA256SUMS.txt。

运行 `npm run smoke -- --ideas --packaged` 可复验卡片与退出；报告和截图在忽略的 `out/review-idea-close/`。常规回归只使用临时生成数据。可选的本地项目诊断也会先复制到独立临时目录，不打开原件进行写入。
