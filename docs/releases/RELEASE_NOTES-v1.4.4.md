# WaterCut v1.4.4 架构重构

2026-11-24。沿用 Electron、React、SQLite 和现有运行依赖版本，继续提供 Windows x64 便携 ZIP。项目格式 v11、总库格式 v4 不变。

## 模块与运行边界

源码按主进程、预加载、渲染环境、工作线程划分；用户功能分别组织组件，后台分为项目、总库、跨库协调、媒体、AI 建议和交付。原始大文件拆为明确的连接、迁移、事务、读取和编辑服务，原有 SQL 值及执行流程保留。

主入口负责组装，窗口和平台能力独立；业务接口分成 7 组。界面入口连接状态协调器与布局，页面组合和编辑操作独立。音频播放引擎归入预览功能，通用媒体地址和拖拽协议归入界面平台工具。

公开界面 API 和数据线程协议集中定义。数据线程仅接受白名单命令，参数与返回值由具体业务函数推导；原有路径授权与运行时校验继续保留。自动检查禁止越层依赖、私有模块越界和运行时循环。

## 保存和任务保护

自动保存由独立协调器负责，保存任务绑定项目；迟到的自动保存结果仅回填发起项目。保留本地待保存编辑、串行写入、失败重试，以及切换 / 导出 / 关闭前的保存屏障。

窗口文件任务单独管理所有权；取消后等待操作结束才释放。新增 8 项测试覆盖保存竞争、重试、项目隔离、取消收尾和窗口销毁后的进度。PDF 的任务类型收紧为它实际使用的取消信号。
