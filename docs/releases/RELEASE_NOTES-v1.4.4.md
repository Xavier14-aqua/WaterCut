# WaterCut v1.4.4 架构重构

2026-11-24。沿用 Electron、React、SQLite 和现有运行依赖版本，继续提供 Windows x64 便携 ZIP。项目格式 v11、总库格式 v4 不变。

## 模块与运行边界

源码按主进程、预加载、渲染环境、工作线程划分；用户功能分别组织组件，后台分为项目、总库、跨库协调、媒体、AI 建议和交付。原始大文件拆为明确的连接、迁移、事务、读取和编辑服务，原有 SQL 值及执行流程保留。

主入口负责组装，窗口和平台能力独立；业务接口分成 7 组。界面入口连接状态协调器与布局，页面组合和编辑操作独立。音频播放引擎归入预览功能，通用媒体地址和拖拽协议归入界面平台工具。

检查器外壳只分派选中对象，异步资源读取独立；灵感、素材和镜头表单分别归入对应功能。编辑字段、引用与裁剪、关联备注、表单键和保存行为保留。

公开界面 API 和数据线程协议集中定义。数据线程仅接受白名单命令，参数与返回值由具体业务函数推导；原有路径授权与运行时校验继续保留。自动检查禁止越层依赖、私有模块越界和运行时循环。

## 保存和任务保护

自动保存由独立协调器负责，保存任务绑定项目；迟到的自动保存结果仅回填发起项目。保留本地待保存编辑、串行写入、失败重试，以及切换 / 导出 / 关闭前的保存屏障。

窗口文件任务单独管理所有权；取消后等待操作结束才释放。新增 8 项测试覆盖保存竞争、重试、项目隔离、取消收尾和窗口销毁后的进度。PDF 的任务类型收紧为它实际使用的取消信号。

## 最终验收与修正

受测提交 `bef445a7cb408f0cb85cc1f71ca0f745333503b2` 的本机最终包与 [云端第 14 次完整运行](https://github.com/Xavier14-aqua/WaterCut/actions/runs/45333299324) 均通过 149 项测试、212 项原生断言、构建及分发审计。六组原生场景为 19 / 18 / 14 / 27 / 25 / 50 项，三个额外 BGM 场景为 19 / 20 / 20 项；没有删除结果断言或增加失败重试。

最终架构检查为 152 个源码文件、332 条运行时依赖、100 个受控 IPC 调用，无越层或运行时循环。415 个 SQL 值与 4 份模板 / 合成样例对照一致；46 个运行依赖的锁定版本保留。旧源码已从离线备份实际恢复，132 个受版本管理文件与原始字节一致。

验收中先后发现并修正以下问题，失败记录不计作通过：

- 本机重开项目后，流程按钮在加载完成前看起来可点击，而协调器会忽略切换。流程按钮现在随忙碌状态禁用；标题与排序的重开持久化检查通过。
- [第 12 次云端运行](https://github.com/Xavier14-aqua/WaterCut/actions/runs/45331005111) 在格式检查停止：两份剪映模板按 Git 属性检出为 CRLF。格式工具明确忽略参考模板；新目录实际检出为 CRLF 后重新验证通过，模板内容不改。
- [第 13 次云端运行](https://github.com/Xavier14-aqua/WaterCut/actions/runs/45332410886) 在收纳拖拽脚本遇到刷新期间的空节点。脚本现在等待两端可用，并在同一渲染任务内发送一次拖拽手势，仍核对原有归属与跨项目隔离断言。各原生场景的失败报告和截图现在统一上传。

原目录在核对原始 132 个摘要后快进合入，重新安装开发依赖并通过静态检查；受测运行文件复制后再次逐文件校验。最终本机 ZIP 为 159,616,034 字节，SHA-256 `894d2dae56630b2dcb956b2fa76e8b4ecc13fafbb1502203599855dd9b684fbb`；云端内层 ZIP 的独立摘要及下载见 [发布清单](./RELEASE_CHECKLIST.md)。构建指纹按各自检出文件的实际字节计算，Git 提交一致；不宣称跨环境逐字节可复现。

最终记录回填仅修改文档并使用 `[skip ci]`，运行代码、开发脚本、测试、配置和工作流以以上受测提交为准。没有改动真实项目、总库、素材及旧 Release / 标签。原生检查使用静音自动化和合成数据，不替代人工听音或未验证剪映版本的实机兼容性测试。
