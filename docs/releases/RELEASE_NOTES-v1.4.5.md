# WaterCut v1.4.5 界面更新

2026-11-24。按用户六张参考图更新项目首页、白板、脚本、分镜、粗剪和清单。继续提供 Windows x64 便携 ZIP，项目格式 v11、总库格式 v4 不变。

## 视觉与功能

采用米白工作纸、墨黑文字与细框、钴蓝当前流程及主操作、珊瑚色连接点与播放位置。保留 Windows 原生窗口栏、菜单和文件对话框。

首页使用程序生成的几何项目封面；名称、日期、路径、进入和归档操作仍来自真实项目。工作室保持资源、创作、详情三栏和固定导航；新增淡线轨道、画面取景框和空检查器准星。素材图片、视频、参考色彩与色环保留原有内容。

样式入口改为明确的模块导入，主题变量在 `tokens.css`，BGM 归预览、精华归资料库、AI 独立。共享图标和几何组件在 `renderer/ui`。界面规范和维护路径见 [DESIGN.md](../../DESIGN.md) 与 [主题说明](../architecture/界面主题与样式.md)。

独立复核后补齐镜头详情的键盘入口，以及共用对话框的名称、背景隔离、焦点闭环、Esc 关闭和焦点返回。关闭仍遵循各功能原有的忙碌规则。三个桌面宽度均通过真实渲染器内的可信按键验证，事件证据单独保存；不宣称已经过人工屏幕阅读器测试。

## 验证

新增 `--scenario=interface`：使用官方生成示例与两个临时项目，在 1440 / 1280 / 1000 宽度下检查首页、五个流程、非空详情、总库与存储对话框，共 27 张实际程序截图。截图等待图片解码、当前流程与有限过渡稳定后再捕获；检查横向溢出、代表性文字对比、键盘焦点和离线字体 / 图形依赖。

既有保存、拖拽、退出、媒体探测、BGM 同步、AI 确认及交付断言继续保留。验收启动器拒绝使用旧报告，避免新进程启动失败时把上次的结果当成本轮结果。最终本机与云端验收、独立视觉复核和校验值见 [发布清单](./RELEASE_CHECKLIST.md)。

受测提交 `972ba659dd45206efa466fd9577d5a4b4643dc7e` 在本机与 [第 16 次云端完整运行](https://github.com/Xavier14-aqua/WaterCut/actions/runs/45357131224) 均通过 149 项测试、286 项原生断言、打包和分发审计。原有功能仍为 212 项，新增界面与键盘检查 74 项，覆盖 27 张截图、450 个代表性文字测量和 15 次可信按键。最低测得文字对比为 6.17:1；完整人工键盘、屏幕阅读器和人工听音仍不在这项自动化结论之内。
