# WaterCut v1.0.0 预览版

WaterCut 是本地优先的视频创作工作台。此版本面向 Windows x64，提供免安装 ZIP。

## 已实现

- 创建、重命名和重新打开本地项目；分镜与灵感自动保存。
- 导入图片、视频、音频并管理素材；为镜头选择候选画面、主画面和参考音频。
- 调整视频入点和出点，按镜头顺序粗剪预览。
- 在灵感白板拖动卡片、连接和删除连线。
- 使用自己的 OpenAI API Key 根据选中灵感生成可编辑的分镜草案，确认后再加入项目。

## 安装与数据

下载 `WaterCut-win32-x64-1.0.0.zip`，完整解压后运行 `WaterCut.exe`。无需安装 Node.js 或系统 FFmpeg；不配置 AI Key 也能手工创作。仓库外运行时，项目默认保存在用户“文档/WaterCut Projects”。当前程序未签名，Windows 可能显示来源警告。

## 当前限制

这是预览版：没有安装器、自动更新、版本快照、项目包导入导出或正式视频导出。需要跨电脑使用时，请手动复制整个 `.watercut` 项目文件夹。AI 在线调用需要自己的 Key 和可访问 OpenAI API 的网络。

问题反馈请附版本、Windows 版本和复现步骤；不要上传含私人素材或 API Key 的项目。
