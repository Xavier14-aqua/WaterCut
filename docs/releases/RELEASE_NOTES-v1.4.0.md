# WaterCut v1.4.0：阶段 4A

Windows x64 便携预览版，2026-11-19。

后续状态：v1.4.1 已补齐剪映专业版 11.8.0.14778 的基础交接实机验收，见 [实机记录](../acceptance/剪映11.8实机验收.md)。本页保留 v1.4.0 原交付时的状态与摘要。

## 新功能

- 总库视频可命名精华子片段，拖到分镜复制独立裁剪；总库后续修改不影响旧项目。
- 使用足迹按原片区间核对，区分主画面、仅候选、参考音频、BGM 与项目引用，显示真实镜号、离线及过期状态。
- 粗剪增加 BGM 起点、裁剪、片段音量、淡入淡出和独立原声 / BGM 总音量。画面与音乐共用时钟，加载、暂停、定位、后台和设备变化同步处理。
- 拍摄清单增加道具、拍摄准备及场景 / 昼夜 / 缺口筛选，CSV / PDF 共用当前筛选结果。
- AI 支持 2～3 条故事路线、逐条配画面、分镜体检标注和补镜草案。建议先保存，主动采纳才写正式项目；取消 / 失败 / 过期不覆盖手工稿。灵感回声只在本机检索。
- “版本与交付”增加剪映专业版草稿交接试验：复制原件，保留入出点 / 音量 / 配乐，缺素材镜头生成实际文字占位 PNG，并附时间线与文件指纹清单。

## 升级

先退出旧版，再解压新 ZIP 运行。项目升级到 v11、全局库到 v4，升级前建立一致备份，旧应用不能继续写新格式。BGM、拍摄字段与独立裁剪随快照和项目包保存；待确认 AI 建议只留在本项目数据库。

本次包隔离输出到 `out/stage4a/`，不覆盖本机运行中的 v1.3.2。程序和源码不附带私人素材或密钥。
