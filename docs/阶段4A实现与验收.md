## 2. 数据与升级

- 项目格式 v10 → **v11**：镜头新增 `props` / `production_state`；素材绑定新增来源片段 ID / 版本 / 名称；新增 `audio_clips`、`timeline_settings`、`ai_proposals`。
- 全局库 v3 → **v4**：新增 `selects`；`usage_index` 增加镜号、原片区间、片段来源和索引版本。
- 升级前分别建立一致性 `.before-v11.*.bak` / `.before-v4.*.bak`，迁移在事务内完成。旧应用不支持写回新格式；使用新版前先退出旧应用。
- 应用版本、数据库格式、快照文档 / 项目包格式独立。快照及项目包仍为格式 v1，新字段有旧数据默认值；v9 / v10 项目包仍可导入。
- BGM、音量、拍摄字段和裁剪来源随快照保存。独立项目包复制所需原件，清除 live select ID / 版本，保留来源名称和裁剪，避免在别人的库中产生错误依赖。
- AI 待确认建议是本项目数据库中的辅助记录，不改变正式项目 revision。它们不进入正式快照或独立项目包；采纳后的正文、镜头、来源和标注正常保留。
- 启动 / 手动“核对项目索引”扫描已登记项目并重建使用索引；打开或保存项目也会同步。未登记或离线项目无法被当作已全面核验。

## 3. 精华片段与足迹

1. 在总库导入视频，进入详情，必要时“重新探测参数”。只有已知原片时长才开放区间保存。
2. 点“标记精华”，填写名称、入出点、备注；可用预览播放位置作为入点 / 出点。要求 `0 ≤ in < out ≤ duration`。
3. 相交的精华片段给出提示，可以继续保存；不是相同原件的重复拷贝。单原片最多 1000 条可见片段。
4. 工作室资源栏展开原片下的“精华子片段”，拖到分镜卡片。绑定记录当时区间与来源版本。此后总库改片段、隐藏片段或另一项目修改入出点，都不会改旧项目裁剪。
5. 选择片段查看区间足迹。半开区间 `[in,out)` 判断重叠，首尾相接不算重叠。

同镜头、同原件的主画面不再重复计入“仅候选”；项目引用、主画面、仅候选、参考音频和 BGM 分开显示。镜号使用镜头顺序，BGM 使用音频区间，不把 UUID 当镜号。源项目 revision 与索引不一致时显示过期，离线时保留最后核对范围。子片段角标是已知索引中的重叠主画面次数，详情才提供完整角色和状态。

## 4. BGM 与清单

先向项目导入音频，在粗剪底部添加 BGM，设置时间线起点、原片入出点、片段音量及淡入淡出。视频原声与 BGM 总音量独立保存；参考音频继续用于单独试听，不自动当作配乐。

AudioContext 的 `currentTime` 作为唯一播放时钟，视频跟随该时钟。音乐加载完成前不推进画面；视频等待时停止音源并保持定位，恢复时从当前位置重新调度。暂停 / seek 会停止旧音源，异步加载结果有代次检查。切后台、设备变化或音频上下文挂起会一起暂停，用户主动再次播放。实时粗剪仍不是逐帧剪辑器。

每项目最多 128 条 BGM。实时预览每份原件限 64 MB / 10 分钟，解码缓存总计 256 MB；超限、缺失或解码失败给出提示并跳过该 BGM，手工编辑与画面预览仍可继续。交接使用原件，不使用浏览器解码缓存。

镜头检查器可填写道具及“计划中 / 已拍或已备齐 / 需要补拍”。默认清单包括标记待拍、需要补拍以及缺少可用主画面的镜头；手动“已拍”不掩盖原件缺失。取消“仅待拍 / 缺口”可查看所有镜头，再按场景、昼夜、道具或拍摄准备筛选。清单上的 CSV 和 PDF 使用同一筛选对象；版本与交付中的待拍 PDF 同样引用当前筛选。专业交接附带的分镜 CSV 则包含整条时间线。

## 5. 剪映草稿交接

### 输出

直接选择剪映设置中的本地“草稿位置”根目录，生成带随机后缀的 `.jianying` 文件夹，不覆盖任何已有草稿。刷新或重启剪映后在本地草稿列表打开。

```text
项目名-xxxxxxxx.jianying/
  draft_content.json
  draft_meta_info.json
  timeline.json
  分镜清单.csv
  使用说明.txt
  watercut-handoff.json
  media/<SHA-256>.<原扩展名>
```

`TimelineDocument` 保留有理数序列帧率、画布、源映射、片段顺序、源入点、轨道、音量和淡入淡出。每个片段的起止边界先从绝对时间量化为帧，再换算为整数微秒，不逐镜头累计四舍五入。

首轮为一条视频轨、直切、最多 16 条同时重叠的 BGM 音轨。开放 MP4 / MOV 视频、PNG / JPEG 图片、WAV / MP3 / M4A 音频；能探测不等于目标软件能解码每种封装内的编码。可使用 24 / 25 / 30 / 50 / 60 fps 整数序列；内部时间线支持有理数计算，剪映适配器暂拒绝分数序列帧率。

变帧率视频、未知视频帧率、越界区间、离线 BGM、音乐完全位于片尾后和超出支持格式会明确拒绝。带淡入淡出的 BGM 越过画面结尾时要求先手动裁到片尾，避免交接时悄悄改变包络。未提供转码器，不自动规范化这些原件。

无主画面或原件缺失时可启用占位图：在本机生成实际 PNG，写入镜号、画面与对白；内容太长时图片省略，完整文本仍在 CSV / timeline.json。关闭占位选项则拒绝缺原件的交接。

复制与校验在临时目录完成，完成前检查项目 revision，写入文件指纹清单后原子发布；失败或取消清理临时目录。草稿路径指向本次生成目录内已复制的素材。**不要生成后直接移动草稿文件夹再假定路径仍有效**；换电脑推荐先导出 / 导入 WaterCut 项目包，在目标位置重新交接，或在剪映中重新定位。

## 6. AI 建议与本地回声

连接设置收在 AI 抽屉内，使用用户自己的模型与密钥。只有主动生成才调用远程服务。

- “理出 2～3 条故事路线”：选项目灵感后生成多条候选，每条 3～10 镜；选用一条才追加其镜头与来源，不改已有稿。生成后项目变化则不允许直接采纳旧路线。
- “配画面建议”：明确选当前镜头或全片，最多 30 个目标；按镜头显示理由、画面、景别、运镜，允许修改建议再逐条采纳。对白保留。
- “分镜体检”：最多 100 镜，展示逻辑 / 景别 / 节奏 / 缺口建议；可采纳为待优化标注，或明确插入补镜草案。补镜保留来源，镜头与脚本顺序同步，原有未转镜段落不丢失。
- “灵感回声”：450 ms 防抖的本机标签 / 文字关键词检索，展示相关旧卡和已知索引中未作主画面的素材；不会自动联网、自动关联或弹窗。

请求仅包含选中的文字、标签、备注，以及目标镜头画面、对白、预计时长、景别、运镜；对象用本次请求别名表示，不发送实际项目 / 素材 / 库 ID、文件、路径或地点专用字段。文字本身若包含个人信息，会随主动选择一同发送。密钥只用于服务鉴权，以 safeStorage 加密存在本机配置中。

响应执行 Zod 验证、输入目标范围检查、重复建议检查、1 MB 网络响应 / 256 KB 单记录 / 100 条历史上限与 60 秒超时。生成可取消；结构不符、服务失败和取消均不改正式项目。采纳时再次核对目标原稿；被手工改动或已删除的镜头将标为过期，不覆盖。重复采纳拒绝。异常建议历史不会使整个工作室白屏。
